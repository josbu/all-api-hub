All API Hub - 你的全能 AI 资产管家

开源浏览器插件，统一管理第三方 AI 聚合中转站与自建 New API：自动识别账号、比对模型价格、验证 API/CLI 兼容性、同步模型与渠道，并支持跨平台与加密 WebDAV 备份

🚀 开始使用Chrome 商店Edge 商店FireFox 商店Safari 安装

📊 多站点资产看板

一屏掌握多个 AI 中转站的余额、用量、趋势与账号状态，告别分散管理。

🔑 API 凭据库

无需绑定站点账号，把别人分享或平时零散收集的 Base URL 与 API Key 集中收好，需要查询、测试或导出时打开就能用。

💰 跨站模型价格比对

计算各站点模型的折合单价，直观找出更具性价比的模型与分组。

✅ 多站点自动签到

一键或定时完成多站点每日签到，自动领取奖励，免去每天逐站登录。

🧪 API、模型与 CLI 验证

一键测试 API 连通性、模型可用性与 CLI 接入状态，快速排查配置问题。

🔔 公告与任务提醒

集中展示已添加站点的各类公告，维护、模型、价格等动态及时提醒；自动签到、WebDAV 自动同步和模型同步的结果也能及时收到。

🚀 网页录入与一键导出

从网页快速识别 Base URL 或 API Key，并一键导出至常用 AI 客户端。

🛠️ 主流 AI 网关支持

统一管理 New API、AxonHub、Claude Code Hub、Octopus、Veloera、DoneHub；可用已保存的站点账号或 API 凭据库中的凭据快速创建渠道，统一调用模型、灵活切换渠道，也支持模型同步与重定向。

🔐 本地优先与自动同步

数据默认保存在浏览器本地；开启加密 WebDAV 自动同步后，可在多台设备间安全同步，换电脑也能接着使用。

介绍

在 AI 时代，为了省钱或体验不同模型，我们往往拥有多个中转站账号。但管理起来却很头疼：余额分散、价格混乱、每天手动签到太累...

All API Hub 为解决这些问题而生。 它是你的 AI 资产中心，让管理变得简单、直观且自动化。

🎯 你的使用场景

👤 我是普通 AI 用户 (新手推荐)

  • 我该怎么用？：下载并安装扩展 -> 添加第一个账号
  • 我想省钱：自动签到获取额度 -> 跨站模型价格比对
  • 我想更省事：资产变动一眼看清 -> 同步账号到其它 AI 工具

🛠️ 我是进阶玩家 (Key 收藏家)

  • 密钥管理：将独立 URL+Key 保存到 API 凭据库
  • 可用性测试：批量验证接口与 CLI 兼容性
  • 跨端同步：配置 WebDAV 加密备份

👑 我是站点管理员 (站长专区)

  • 效率工具：在插件内直接管理渠道 -> 批量同步模型
  • 配置优化：设置模型重定向
  • 安全保障：处理 2FA / OTP 验证

🧩 支持的系统架构

不论你用的是哪种架构，我们基本都支持：

  • 账号站点兼容架构：New API, One API, Sub2API, One-Hub, Veloera, Done-Hub 等。
  • 特色账号平台与兼容实现：AnyRouter, AIHubMix, Super-API, v-api, Neo-API 等。
  • 自建管理后台：New API, AxonHub, Claude Code Hub, Octopus, Veloera, Done-Hub 等，用于渠道管理、迁移和部分模型同步。
